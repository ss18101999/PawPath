# Launch Checklist

## Before Store Build

- Confirm final brand name.
- Check domain availability.
- Check trademark risk.
- Create Shopify store.
- Create business support email.
- Decide whether to use Spocket, Zendrop, CJdropshipping, TopDawg, or Doba.

## Products

- Import 6 launch products.
- Confirm supplier ships to the United States.
- Confirm supplier delivery estimate.
- Confirm supplier return/replacement process.
- Confirm tracking number automation.
- Remove supplier branding from product titles.
- Rewrite descriptions using `STORE_COPY.md`.
- Add clean product images.
- Add product videos where available.
- Set product status to active only when ready.
- Keep bundles in draft until bundle app/setup is confirmed.

## Shopify Store

- Install Dawn or another free Shopify theme.
- Add logo.
- Set brand colors.
- Build homepage sections.
- Create collections.
- Build main menu and footer menu.
- Create About, Contact, FAQ, Shipping, Refund, Privacy, and Terms pages.
- Add policies to footer.
- Add announcement bar.
- Add trust badges only if they are accurate.

## Checkout

- Enable Shopify Payments.
- Enable PayPal.
- Enable Shop Pay.
- Set USD as currency.
- Configure US shipping zone.
- Add free shipping over $50.
- Test checkout.
- Confirm order confirmation email.
- Confirm shipping confirmation email.

## Apps

- Dropshipping supplier app.
- Judge.me Product Reviews.
- Shopify Inbox.
- Shopify Email.
- Meta Pixel app.
- TikTok app.
- Google & YouTube app if using Google channels.

## Legal And Compliance

- Review policy drafts.
- Add real business contact details.
- Add supplier-specific shipping language.
- Avoid medical claims on slow feeders or enrichment products.
- Avoid fake countdown timers, fake reviews, or misleading scarcity.
- Add safety language for pet products.

## Test Orders

- Place at least one test order for the hero product.
- Confirm order flows into supplier app.
- Confirm tracking is generated.
- Check packaging quality.
- Check delivery time.
- Take your own product photos/videos if possible.

## Marketing

- Create TikTok account.
- Create Instagram account.
- Create Meta Business account.
- Create ad account.
- Install pixels before ads launch.
- Prepare 9-12 short video creatives.
- Prepare launch discount code if using one.
- Create welcome and abandoned checkout emails.

## Launch

- Publish theme.
- Remove password page.
- Place one final live checkout test.
- Open store on mobile and desktop.
- Check all footer links.
- Check product variant selectors.
- Check cart and checkout.
- Start organic posts.
- Launch small paid test only after test order is successful.

## First Week After Launch

- Monitor support email daily.
- Check supplier inventory daily.
- Watch ad comments for objections.
- Check page speed on mobile.
- Pause products with supplier issues.
- Update FAQs based on customer questions.
- Track delivery times for every order.

## Do Not Scale Until

- At least one test order has arrived successfully.
- Product pages have real images/videos or high-quality supplier assets.
- Shipping times are accurate.
- You have at least one ad or organic post generating profitable intent.
- Refund/complaint signals are low.
